# Advanced Selenium Automation Project

## Project Description
This project demonstrates advanced Selenium WebDriver automation using Java, TestNG, Maven and Page Object Model design pattern.

## Technologies Used
- Java
- Selenium WebDriver
- TestNG
- Maven
- WebDriverManager
- Extent Reports
- GitHub
